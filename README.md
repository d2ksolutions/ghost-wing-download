# Ghost Wing — trang tải bản Android

Trang tải công khai cho **Ghost Wing**, demo bay ném bom arcade hư cấu (máy bay cánh bay Nightwing trên quần đảo Vesper), làm bằng Godot Engine 4.7.

- Trang tải: https://d2ksolutions.github.io/ghost-wing-download/
- File APK: xem mục [Releases](https://github.com/d2ksolutions/ghost-wing-download/releases)

Repo này chỉ chứa trang web và các bản phát hành; mã nguồn game không nằm ở đây.

Bản 0.1.0 là bản thử nghiệm (ký bằng khóa debug), dành cho Android 7.0+ trên điện thoại 64-bit (arm64-v8a).
